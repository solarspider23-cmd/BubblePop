# Sunspire Canyon Bazaar - Studio setup

Files: `roblox/` = export of `canyon_map.blend` with `--materials --hero SunTemple --rock
"(?i)rock|cliff|boulder|stone|crag|mesa|butte|stalag|hoodoo"` (hoodoos are rock spires: bedded into the shelves on
purpose, so they are rocks for the placement check) (sand floor = Sand, cliffs / hoodoos /
ashlar = Sandstone, paving = Limestone, timber = Wood, cloth / rope / rugs / sacks = Fabric, palms / agave = LeafyGrass,
scrub = Grass, brass = Metal, pots = SmoothPlastic, terracotta trim = Brick, water = Glass). Nothing is imported yet.
Budget (report.md): 251 placements, 291k placed triangles (hard budget 450k), largest prop `SunTemple` 15.1k, placed at
scale 1.35 (hero budget 30k), every other prop <= 5.2k, 12 static chunks, `EXPORT_OK`, every placement check at 0
(clip, float, water, falls, collision). Placement rules in canyon_map.py: nothing auto-grounded goes under the cliff
overhang (`under_wall`, a ray against the built Cliff_Walls) or onto the wall face itself; parapet niches never overlap
(ledge runs every 8.4, the market-gate wings are 7.6 niches on an 8 pitch: `Parapet7`).

## Import
1. File > Import 3D: every GLB in `roblox/kit/` and `roblox/static/` + `roblox/AxisProbe.glb` (scale unit studs,
   pivot at scene origin, anchored). Put the imported models in one Folder `ServerStorage.SunspireBazaarKit`.
2. ModuleScript `ServerStorage.SunspireBazaarSetup` = `roblox/SunspireBazaarSetup.lua`; run
   `roblox/SunspireBazaarKitPrep.lua` once in the command bar (collision fidelity per prop).
3. AxisProbe: its arrow must point along the model's LookVector (-Z). If it points backwards set `M.YAW_FIX = 180`.
4. Command bar:
```lua
local S = require(game.ServerStorage.SunspireBazaarSetup)
S.LightKeys.temple = true; S.LightKeys.relic = true          -- temple door / sun disc and the relic gem get PointLights too
S.Build(game.ServerStorage.SunspireBazaarKit, workspace)
S.ApplyLook()
-- crisp dusk: warm gold key from the SSW up the canyon, cool blue-violet shadows, light haze, gold horizon -> blue-violet top
local L = game.Lighting
L.Technology = Enum.Technology.Future
L.Brightness = 2.6                                                -- ApplyLook already picked ClockTime from the Blender sun
L.Ambient = Color3.fromRGB(70, 74, 120); L.OutdoorAmbient = Color3.fromRGB(110, 118, 170)
L.ColorShift_Top = Color3.fromRGB(255, 190, 120); L.ColorShift_Bottom = Color3.fromRGB(40, 50, 110)
local atm = L:FindFirstChildOfClass("Atmosphere") or Instance.new("Atmosphere", L)
atm.Density = 0.2; atm.Offset = 0.05; atm.Haze = 0.4; atm.Glare = 0.3
atm.Color = Color3.fromRGB(255, 226, 190); atm.Decay = Color3.fromRGB(110, 120, 190)
local cc = L:FindFirstChildOfClass("ColorCorrectionEffect") or Instance.new("ColorCorrectionEffect", L)
cc.Saturation = 0.15; cc.Contrast = 0.12
for _, p in workspace.SunspireBazaar:GetDescendants() do
    if p:IsA("PointLight") then p.Range = 9; p.Brightness = 0.8; p.Shadows = false; p.Color = Color3.fromRGB(255, 160, 80) end
    if p:IsA("MeshPart") and p.Material == Enum.Material.Glass then p.Transparency = 0.15; p.Reflectance = 0.05 end
end
```
Compare a Studio screenshot from the spawn with `previews/map_spawn.png`; tune `M.Look` / the numbers above, not the
build. Beauty camera (menu / lobby shot): `CFrame.lookAt(Vector3.new(16, 34, 268), Vector3.new(-6, 24, -230))`,
`FieldOfView = 36`.

## Gameplay hooks
Positions are Roblox studs from `hooks.json` (generated by `canyon_map.py`). Every station has a BLANK sign face (cream
board in a carved timber frame): put a SurfaceGui on it or use an invisible anchor Part at the point below. No text is
modelled anywhere.

| Hook | Position (x, y, z) | Facing (yaw) | What |
|---|---|---|---|
| `Spawn` | (0, 0.3, 226) | 0 (looks -Z, up the canyon) | star medallion in the spawn plaza |
| `QuestBoard` | (17.9, 8.75, 200.1) | 110 | sign above the board; 3 cream panels = quest SurfaceGuis |
| `TraderPavilion` (sell) | (-24.5, 7.1, 40.0) | -90 (faces +X) | sign on the pavilion front, counter + scale + coin chests |
| `RelicKiosk` (pets / relics) | (37.4, 26.6, -66.3) | 70 | sign on its stand on the east ledge; glowing relic gem = display spot |
| `ForgeStation` (upgrade) | (-37.2, 4.4, -211.0) | -90 (faces +X) | sign on posts beside the glowing hearth + anvil |
| `TempleDoor` (rebirth / teleport) | (-8.6, 6.1, -271.1) | 180 (faces +Z) | glowing doorway, opening 12 wide x 19.5 high, 8 deep |

```lua
-- invisible anchors + spawn (run after Build)
local HOOKS = {
    {"QuestBoard", Vector3.new(17.86, 8.75, 200.05), 110}, {"TraderPavilion", Vector3.new(-24.46, 7.1, 40.0), -90},
    {"RelicKiosk", Vector3.new(37.44, 26.6, -66.3), 70}, {"ForgeStation", Vector3.new(-37.21, 4.4, -211.0), -90},
    {"TempleDoor", Vector3.new(-8.60, 15.58, -271.14), 180},
}
local f = Instance.new("Folder"); f.Name = "StationAnchors"; f.Parent = workspace.SunspireBazaar
for _, h in HOOKS do
    local a = Instance.new("Part"); a.Name = h[1]; a.Anchored = true; a.CanCollide = false; a.CanQuery = false
    a.CanTouch = h[1] == "TempleDoor"; a.Transparency = 1
    a.Size = h[1] == "TempleDoor" and Vector3.new(12, 19, 4) or Vector3.new(4, 1.8, 0.4)
    a.CFrame = CFrame.new(h[2]) * CFrame.Angles(0, math.rad(h[3]), 0)   -- front face (-Z) = the sign's readable side
    a:SetAttribute("Station", h[1]); a.Parent = f
end
local sp = Instance.new("SpawnLocation"); sp.Name = "CanyonSpawn"; sp.Anchored = true; sp.Transparency = 1
sp.CanCollide = false; sp.Size = Vector3.new(8, 1, 8); sp.CFrame = CFrame.new(0, 0.6, 226); sp.Parent = workspace
```
Put a SurfaceGui with `Face = Front` on each anchor (or a BillboardGui / ProximityPrompt).

## Paths and traversal
- Main path: flagstone street from the plaza (z 175) along the canyon centre to the temple court; it swings ~16 studs
  east round the oasis pool. Branches: oasis -> east stair foot, oasis -> Trader Pavilion, narrows -> west stair foot.
- Side loop: `CarvedStair24_1` (east wall, z +20 -> -20, rises 24 to the east ledge) -> east ledge (12-19 wide,
  parapet niches on the lip) -> Relic Kiosk -> `RopeBridge60` (y 24, z -95, spans the narrows) -> west ledge ->
  `CarvedStair24_2` (z -104 -> -144) back down to the floor.
- Bounds: the canyon walls (precise collision) and the temple wall close the north. The south mouth opens onto dunes:
  add an invisible wall at z = 262 (x -80..80) if players must stay in the hub. The second riser (24 -> ~52) keeps
  players off the mesa tops.

## Collision
Ground, cliffs, paving, temple, gate, stairs, bridge, pool and station pavilions `precise`; stalls, shade sails,
parapets, lantern posts, braziers, quest board and story clusters `box`; palms, hoodoos, boulders `hull`; scrub,
agave and dry grass `none`. Rules: the Sunspire line at the top of `COLLISION` in `scripts/roblox_export.py`.

## Glow
The temple stands in a rectangular niche cut into the end wall (stepped chiselled surround, cliff strata continuing
beside and above it); Neon `temple` glow on the doorway, sun disc and tholos window is the goal you see through the gate.

Neon keys: `lamp` (brass lanterns: parapet niches, posts, gate, stair newels, quest board), `fire` (braziers, forge
coals), `temple` (doorway + sun disc + tholos window), `relic` (kiosk gem). 101 lantern points are listed in
`hooks.json` (`lamps`) if you want PointLights placed by hand instead of `LightKeys`.
