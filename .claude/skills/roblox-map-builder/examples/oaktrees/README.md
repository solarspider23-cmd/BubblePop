# Oak trees (realistic alpha-card set)

Original trees in the classic Studio oak style: three MeshParts each (Trunk / Branches / Leaves),
SurfaceAppearance color + normal maps. Everything is generated by `gen_trees.py` (geometry and textures, no photos
or downloaded assets). Opt-in exception to the map skill's "no alpha cards" rule.

Rebuild (headless, ~15 s for all four incl. renders):

    blender -b --factory-startup --python gen_trees.py -- [--only OakA,Birch] [--norender] [--noexport]

Tune a tree in the `TREES` table (trunk, crown envelope, per-level branching, leaf card density / gaps / size).
`report.json` holds the counts; `renders/<Tree>_sheet.png` = reference crop + 4 turntable angles.

## Using them in a map (no copy needed)
```python
sys.path.insert(0, os.path.join(HERE, '..', 'oaktrees')); import gen_trees as GT
objs, tris, tree = GT.make_tree('PineA', kit_collection, prefix='Tree', tex={'fir': 'fir_v', 'oak': 'oak_v'})
```
`make_tree` returns the three objects (`TreePineA_Trunk` / `_Branches` / `_Leaves`, one origin) and their triangle
counts; place all three with the same matrix. Textures load from `roblox/textures/` when they exist (painted once).
`tex` maps a species' texture style to a map grade from `TINTS` (leaf gain + saturation, bark gain): `oak_v`,
`young_v`, `fir_v`, `blossom_v` (Mistvale Lake, cyan haze), `oak_t`, `birch_t` (Maple Junction, sunny street). Graded
colour PNGs are named `<base>_<v|t>_*_color.png` and reuse the base normal maps. They are cached: after changing a
base painter or a grade, delete the matching `_<v|t>_` PNGs (a standalone run repaints only the base files).
Wired in: `examples/valleylake/valley_map.py`, `examples/towncity/town_map.py` and `examples/dunedesert/dune_map.py` (kit keys `r<Species>`). The exporter
(skill `scripts/roblox_export.py`) knows these names: cards collision none, no float / UV warnings for them, and the
setup module sets AlphaMode / DoubleSided and never puts the palette TextureID on a part with a SurfaceAppearance.

## Files (`roblox/`)

- `<Tree>.glb` - all three parts, shared origin (trunk base). **Import this one**: the parts stay aligned.
- `<Tree>_Trunk.glb`, `<Tree>_Branches.glb`, `<Tree>_Leaves.glb` - one part each, same origin (for re-importing a single part).
- `textures/` (PNG, also embedded in the GLBs), one set per texture style (`oak` = OakA / OakB / OakHero / StreetOak, `birch` = Birch / StreetBirch, `young`, `blossom` (leaves only; bark + twigs = oak), `fir` = PineA-C; plus the map grades above):
  - `<style>_bark_color.png` 1024, `<style>_bark_normal.png` 1024 (tileable)
  - `<style>_leaves_color.png` 1024 RGBA (4 x 4 atlas = 16 leaf-cluster variants, alpha cut-out), `<style>_leaves_normal.png` 1024
  - `<style>_twigs_color.png` 512 RGBA (2 x 2 twig sprays), `<style>_twigs_normal.png` 512
  Normal maps are OpenGL convention (green = up), which is what glTF and Roblox use.

## Import into Studio

1. File > Import 3D > pick `roblox/<Tree>.glb`.
2. Settings: Import as Model; scale unit / file dimensions = **Studs** (authored 1 unit = 1 stud; OakA should read ~27 x 23 x 27);
   Set pivot to scene origin (pivot = trunk base); Anchored on; keep Textures / Materials on so SurfaceAppearances are created.
3. On each MeshPart's SurfaceAppearance set AlphaMode:
   - `*_Trunk`: **Overlay**
   - `*_Branches`: **Transparency**
   - `*_Leaves`: **Transparency**
4. On `*_Branches` and `*_Leaves`: DoubleSided = true (the GLB marks them double-sided; check the importer kept it,
   otherwise the cards vanish from behind), CastShadow on, CanCollide / CanQuery / CanTouch off (cards), and
   CollisionFidelity Box. Trunk: CollisionFidelity Hull or a separate invisible cylinder.
5. If the importer drops a texture, upload the PNG from `textures/` and set it as ColorMap / NormalMap by hand.

The importer turns GLBs 180 degrees about Y; the trees are roughly round so it doesn't matter (OakB leans +X in Blender).

## How it is built

- Skeleton: recursive branches (trunk, 4-7 limbs, secondary, tertiary) with gravity droop, phototropism, random wander,
  golden-angle spread, and every branch length fitted inside a lumpy ellipsoid crown envelope. Tubes are meshed directly
  (parallel-transport rings, 12/8/6/4/3 sides by level), lobed root flare + noise on the trunk, bark UVs scaled so the
  texture keeps its aspect (1 tile = `bark_tile` studs).
- Twig cards: crossed pairs near the branch ends. Leaf cards: folded quads (4 tris) along outer branches and at tips,
  facing out from the crown with an upward bias and jitter, bent (custom) normals toward the crown surface so lighting
  reads as one canopy, 3D-noise holes for sky gaps, the hidden core thinned, no cards below `zmin`.
- Textures: painted with numpy inside Blender's Python: periodic FFT noise (tileable bark ridges, cracks, lichen; birch
  lenticels + black patches), signed-distance leaves (lobed oak / ovate serrated) with midrib + side veins, light/dark
  variation, soft edges, colour bleed under transparent pixels; normals from height.

## Weaker than the reference

- Leaf clusters read flatter and more "card-like" up close (visible straight card edges at grazing angles, some streaky
  edge-on cards); the reference crown is denser and more blobby with darker interior shading.
- No ambient occlusion baked into the leaf/trunk colour: the crown interior is not as dark as the reference's.
- Branch junctions are overlapping tubes, not welded; a close-up shows the seam where a limb enters the trunk.
- Bark is procedural noise: convincing at game distance, plainer than a photo-scanned bark up close.
- OakB is narrower (15 studs) on one axis; Birch's top leader shows a bare tip from some angles.
- Firs: the top whorls still read a little ragged (sparse flat sprays sticking out); the frond atlas is orderly, so up
  close the sprays look a bit fern-like; edge-on spray cards show as thin blades at the silhouette.
- OakHero: the crown can show a gap between its two main lobes from some angles; roots are tubes laid on the ground,
  not welded into the trunk flare.
- Birch / StreetBirch: the bare leader tip shows above the crown.
- Map grades are tuned in Blender's EEVEE preview, not in Roblox lighting.
- Not seen in Studio yet: AlphaMode, DoubleSided and the import scale are untested on these files.
