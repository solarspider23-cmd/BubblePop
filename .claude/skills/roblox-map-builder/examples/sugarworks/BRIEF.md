# Sugarworks Tycoon (brief)

**Game:** factory tycoon. Each player claims a plot, buys droppers / conveyors / upgraders with buttons, sells at the collector.
**Archetype:** tycoon plots (map_archetypes.md). 8 identical plots, 2 rows of 4 along one boulevard.

- Size: plateau x +-150, z -300..250 (300 x 550), cliffs down to a sunset sea. Flat (y 0) - plots must be equal.
- Spawn: south plaza (0, 205) facing north up the boulevard. Hero at the north end = the **Candy Exchange** (domed hall,
  gumball crown, glowing ring) closing the vista. Lollipop towers flank it.
- Plot (84 x 84, gate on the road side): owner gate + claim pad, fence with team-colour glow strip, starter line
  dropper -> conveyor -> upgrader -> collector, cash pad, 3 buy buttons, empty slots (corner markers) for the next line.
- Road: 32 wide asphalt, kerbs, lane dashes, candy-cane lamps every 40. Lawns: lollipop trees, gumdrop bushes, benches.
- Palette: cream / concrete / asphalt base, candy pink + mint + lemon + grape accents, chocolate. Team colours only as glow.
- Look: golden-hour sunset (low warm sun, pink-violet sky), lamps lit.
- Not this: bowl + rim, forest/grove props, noon light, terrain hills, uneven plots.
